# Privacy

- Personal data stays on this machine. Never put names, emails, phone numbers or addresses into URLs, search queries or web tools.
- Never store passwords, tokens, card numbers or account numbers in any memory file, brief or log.
- `.env`, `*.key` and `*.pem` are off limits (also enforced in settings.json).
- Contents of private files and messages are not pasted into web tools, even to "check" something.
